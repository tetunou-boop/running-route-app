# JR東日本グループ会社ガイド

JR東日本グループの会社（約70社）を検索・閲覧できる、フロントエンドのみの単一ページアプリです。
データは公式サイト「グループ会社一覧」等の公開情報のみを使用しています（出向・転籍の実績等の社内情報は含みません）。

## 機能

- セグメント別（運輸／流通・サービス／不動産・ホテル／その他）のカテゴリボタンによる絞り込み（複数選択可）
- 会社名・事業内容・所在地でのフリーテキスト検索（インクリメンタル検索）
- 都道府県での絞り込み
- カードタップで会社詳細（事業内容全文・公式サイトリンク・セグメント）をモーダル表示
- スマートフォンでも見やすいレスポンシブデザイン

## 構成

```
index.html               エントリーポイント
css/styles.css           スタイル
js/app.js                検索・フィルタ・モーダルのロジック
data/group_companies.json  会社データ（更新時はこのファイルを差し替えるだけでOK）
```

## ローカルでの起動方法

`fetch` でJSONを読み込むため、簡易HTTPサーバー経由で開いてください（`file://` では動作しません）。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## データの更新

`data/group_companies.json` を最新の公式情報に差し替えるだけで反映されます。
更新時は `meta.last_checked` の日付も更新してください。
出典: [JR東日本公式サイト「グループ会社一覧」](https://www.jreast.co.jp/company/about/group/)
