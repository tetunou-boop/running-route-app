# JR東日本グループ会社ガイド

JR東日本グループの主要な会社を検索・閲覧できる、フロントエンドのみの単一ページアプリです。
データは公式サイト「グループ会社一覧」等の公開情報のみを使用しています（出向・転籍の実績等の社内情報は含みません）。

**注意**: 本アプリが掲載しているのは公式サイト「グループ会社一覧」ページに載っている主要な子会社・関連会社です。
JR東日本グループには、この一覧に載らない孫会社（子会社がさらに出資・設立した会社）や非連結子会社等も多数存在し、
IR資料・統合報告書ベースの連結子会社・持分法適用会社は約87社、孫会社等を含めたグループ全体では100〜140社程度
とされています。本アプリの掲載社数はグループ全体の総数ではありませんのでご注意ください。

## 機能

- セグメント別（運輸／流通・サービス／不動産・ホテル／その他）のカテゴリボタンによる絞り込み（複数選択可）
- 会社名・事業内容・所在地でのフリーテキスト検索（インクリメンタル検索）
- 地域（都道府県・海外）での絞り込み
- カードに本社所在地の住所を表示
- 会社の略称・通称（判明しているもののみ）をカード名の横に表示、検索対象にも含む
- 「略称から探す」パネルで略称一覧（アルファベット順）をチップ表示し、クリックで即絞り込み
- カードタップで会社詳細（事業内容全文・設立年・資本金・社員数・公式サイトリンク・セグメント）をモーダル表示
- スマートフォンでも見やすいレスポンシブデザイン

## データについて

設立年・資本金・社員数・略称はWeb検索経由で収集した情報を含みます。情報源によって数値が食い違う項目や、
公式に使われている確証が得られなかった略称は `null`（未掲載）としており、必ずしも最新・正確とは限りません。
正確な情報は各社公式サイトでご確認ください。

## 構成

```
index.html               エントリーポイント
css/styles.css           スタイル
js/app.js                検索・フィルタ・モーダルのロジック
data/group_companies.json  会社データ（更新時はこのファイルを差し替えるだけでOK）
dist/index.html           CSS・JS・データを1ファイルに埋め込んだ配布用HTML（Netlify等へのデプロイ用）
```

## ローカルでの起動方法

`index.html` は `fetch` でJSONを読み込むため、簡易HTTPサーバー経由で開いてください（`file://` では動作しません）。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

`dist/index.html` はCSS・JS・データがすべて1ファイルに埋め込まれているため、`file://` で直接開いても動作します。

## Netlifyへのデプロイ

`dist/index.html` をそのままNetlifyのドラッグ&ドロップデプロイ画面に投げ込むだけで公開できます
（1ファイル完結・外部依存なし）。`index.html`/`css`/`js`/`data` 一式のフォルダをデプロイする場合も、
静的サイトとしてそのまま動作します。

`data/group_companies.json`、`index.html`、`css/styles.css`、`js/app.js` のいずれかを更新した場合、
`dist/index.html` には自動反映されません。以下のスクリプトで再生成してください。

```bash
python3 scripts/build_dist.py
```

## データの更新

`data/group_companies.json` を最新の公式情報に差し替えるだけで反映されます（`index.html` 利用時）。
更新時は `meta.last_checked` の日付も更新してください。
